# Posterity Impact Initiative

Website and backend for Posterity Impact Initiative, a Nigerian non-profit.

- **Pages**: plain HTML, CSS and JavaScript, generated by `tools/build.py` so every page
  shares one header and footer.
- **Backend**: serverless functions in `api/` (hosted on Vercel) backed by a Supabase
  database. Paystack handles payments.
- **Staff area**: `admin.html`, for opportunities, expenses, messages and subscribers.

To put it live, follow [SETUP.md](SETUP.md).

## Editing pages

Edit the content in `tools/build.py`, then run:

    python3 tools/build.py

## Running locally

    node tools/dev-server.js

Opens the full site, API included, at http://localhost:8787 using a temporary practice
database.

## How the data flows

| Feature | Where it is stored | How it changes |
|---|---|---|
| Donations | `donations` table | Paystack calls `/api/paystack-webhook` after each payment |
| Expenses | `expenses` table | A signed-in admin adds them |
| Public ledger | Built from the two tables above | `/api/ledger`, never shows donor names |
| Opportunities | `opportunities` table | A signed-in admin adds, edits and removes them |
| Newsletter | `subscribers` table | `/api/subscribe` |
| Contact messages | `messages` table | `/api/contact` |

If the API is unreachable, the ledger and the opportunities board fall back to the
files in `data/`, so the pages never appear broken.
